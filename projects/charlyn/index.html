what it is

Charlyn is an ai agent that can do things instead of just talking. browse the web, read screenshots, edit files, run code, remember what you told it, keep a conversation going. it lives in the terminal and on discord. there's also a roblox script in there because i couldn't help myself.

3llm backends
~20tools
1docker container per user
jsonmemory, ai decides

the story

  • it started as a cli agent. i wanted an assistant that could do things, so i gave it tools: a browser, a terminal, files. that was the whole first version.
  • i didn't want to be locked to one model. so the llm client talks to three backends: ollama, openai-compatible apis, and github copilot. tool calls from each get normalized into the same shape, so the agent logic doesn't care which model is driving it. there's a planner mode for big tasks and history summarization so long conversations don't blow up the context window.
  • the toolset grew from there. playwright for browser control, ocr for reading images, web search and scraping, username lookup, dns and whois, wayback, anime and manga lookup. it's a toolbox, not a chat.
  • memory is json files. the ai decides what's worth remembering, and per-user files keep people's stuff separate. a limit stops memory from crowding out the actual conversation.
  • the scary part is code execution. i wasn't going to let an ai run arbitrary commands on my machine, so each user gets a docker container. read-only root filesystem, cpu and memory limits, and a blocklist for escape commands like docker, nsenter, and chroot. the ai can run code, it just can't leave the box.
  • then it moved to discord. because that's where people already talk. embeds, per-user agents, a whitelist, a per-user model and host. the cli still works, they share the same brain.
